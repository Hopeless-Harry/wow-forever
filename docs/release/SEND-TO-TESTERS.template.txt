INSTALL
1. Fully close World of Warcraft.
2. Open the ZIP.
3. Copy the MAMChronicles folder into the AddOns folder of your client:
   World of Warcraft\_retail_\Interface\AddOns\
   World of Warcraft\_classic_beta_\Interface\AddOns\   (WoW Forever)
4. Start WoW and enable "Moms Against Magic Chronicles" on the AddOns screen.
5. Log in and type: /mam

QUICK TEST
1. Read the Getting started card on Home, then click Got it.
2. Type: /mam toast   (shows a test toast)
3. Open the Medals tab: try the filters, the search box and hover a medal.
4. Type: /mam remember tester check
5. Type: /reload
6. Open /mam and confirm the memory is still present.
7. Work through TESTER-CHECKLIST.md where practical.

IF SOMETHING BREAKS
1. Type: /mam diag
2. Click "Copy diagnostics", press Ctrl+C, and paste the report into your message.
   (It holds no chat, gold, item names or character name.)
3. Include exactly what you did immediately before the problem.
4. On WoW Forever please send /mam diag even when nothing broke: we still need to
   confirm campfire, emote, consumable and other detection there.

IMPORTANT
- This is an alpha build. Back up the WTF folder before extended testing.
- Retail testing does not prove WoW Forever compatibility.
- Do not send SavedVariables files publicly; they contain your gameplay history.
- Guild announcements of new medals are on by default; turn them off in Settings > Alerts.
